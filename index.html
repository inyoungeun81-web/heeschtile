헤슈 타일링(Heesch Tiling) 탐구

중학교 수학 테셀레이션 인터랙티브 학습지

개념 1

도형 변환에서의 이동

테셀레이션을 만들기 위해 도형의 변을 이동시키는 4가지 기본 합동 변환의 원리를 살펴보세요.

T : Translation 평행이동 (옮기기)

도형을 한 방향으로 일정한 거리만큼 그대로 움직이는 변환입니다.

C : Center Point Rotation 변 중심 회전이동 (180°)

다각형 변의 중점을 회전 중심으로 180° 돌리는 점대칭 변환입니다.

C₄ : Corner Rotation 꼭짓점 회전이동 (90°)

사각형의 꼭짓점을 중심으로 변을 90°만큼 돌려 이웃하는 변으로 이동합니다.

G : Glide Reflection 미끄럼 반사 (뒤집어 옮기기)

도형을 대칭축을 중심으로 뒤집은(반사) 후, 축 방향으로 평행이동합니다.

헤슈 타일링에서 '순수 반사(Reflect)'를 제외하는 이유:

단순히 뒤집기만 하는 반사 변환은 무늬를 연속으로 연결할 때 제약이 너무 많아집니다. 따라서 하인리히 헤슈는 평행이동(T), 회전이동(C), 미끄럼 반사(G)만을 활용하여 28가지 기본 타일 타입을 정립하였습니다.

개념 2

정사각형 기반 헤슈 타일 5가지

사각형으로 평면을 빈틈없이 채울 수 있는 헤슈의 5가지 변형 조합 규칙을 알아봅니다.

TTTT 타입 상세 설명

TTTT : 평행이동 + 평행이동

위쪽 변을 변형시키면 아래쪽 변이 똑같은 모양으로 평행이동($T$)하여 연동됩니다. 왼쪽 변을 변형시키면 오른쪽 변도 똑같이 평행이동($T$)하여 이동합니다.

위-아래 변 관계: 평행이동 (T)
좌-우 변 관계: 평행이동 (T)
헤슈 타입:
변의 점(조절점)을 드래그하세요! 대응되는 변이 실시간으로 변형됩니다.
